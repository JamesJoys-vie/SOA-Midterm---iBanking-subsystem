What changes here

Reserved tuition: yours or someone else's

The tuition has one status, RESERVED, but what you can do depends on who holds it. The API does not say who, so the app compares it with your own transactions. No endpoint changes.

Implementation plan

Four phases on the existing React and Tailwind stack, each one reviewable on its own branch.

Phase 1

Foundations

Tailwind @theme tokens, Be Vietnam Pro, lucide-react icons, shared Input and Dialog, and status labels. The layout stays as it is.

Phase 2

UX and accessibility fixes

In-app cancel dialog, focus trap and Esc, visible failure reason, idle reason on Confirm, and aria-invalid on fields. Worth doing even without the redesign.

Phase 3

Layouts

App shell, then Home, Pay, Result and History with its details panel, one branch at a time.

Phase 4

Optional polish

Dark mode, a Vietnamese and English switch, and a printable receipt.
