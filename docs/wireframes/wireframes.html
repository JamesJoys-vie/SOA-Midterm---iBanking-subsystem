Notes

  1. Recap of what is being paid, so the user knows what they confirm.
  2. 6 single-digit boxes: auto-advance, paste fills all, Backspace goes back. Numeric keyboard on mobile.
  3. Countdown from otp_expires_in (5 min). At 00:00 the boxes disable and "Code expired — resend" shows.
  4. Resend disabled during a short cooldown, then POST /transactions/{id}/resend-otp; 429 shows "Too many requests". Timer resets.
  5. Verify enabled when 6 digits entered → POST /verify-otp. Cancel → POST /cancel, closes modal. 400 shows inline error (shown here).

Modal can't be closed by clicking the backdrop (avoid losing the transaction by accident); ✕ asks "Cancel this payment?".

Component inventory

frontend/src/components

AppLayout

Header (logo, nav, user name, Sign out) + centered <main>. Wraps every protected route.

StatCard

Label + big number + small caption. Used in the Home stat row.

PendingPaymentsCard

Lists PENDING_OTP transactions with countdown, Resume and Cancel. Hidden when empty.

Card

White box with title + optional right-side hint. Used for every section.

Field / ReadOnlyField

Label + input (or gray read-only value) + help / error text.

Button

Variants: primary, secondary, ghost; loading and disabled states.

Alert

Inline message inside a card (error / info). Never a page-level popup.

StatusBadge

Maps UNPAID, PAID, PENDING_OTP, PROCESSING, SUCCESS, FAILED, CANCELLED, EXPIRED to a style.

Stepper

Details → Verify OTP → Result, used on /pay and in the modal.

Money

Formats VND with thousand separators + "₫"; tabular digits. Renders •••••••• ₫ when amounts are hidden (fixed width, aria-label="Amount hidden"). Every ₫ value goes through it.

AmountVisibility (context + EyeToggle)

Global hidden flag + toggle, persisted in localStorage, default hidden. Visual privacy only: values are still in the API responses.

PayerCard / TuitionCard / ConfirmCard

The three sections of /pay. ConfirmCard owns the enable-rule for the button.

OtpModal + OtpInput

6-box input, countdown, resend cooldown, verify / cancel.

ResultCard

Success / failure variants, reused for history row details.

HistoryTable

Toolbar filters, table, empty / loading / error states. Compact mode (no toolbar, 5 rows) on Home.
